# 99 參考資料

本頁只列能直接支撐正文 API、版本、operation 和 security claim 的一手來源。版本與支援狀態最後檢查日為 **2026-09-15**；第三方套件、container image、Kubernetes add-on 和 broker release 仍要在部署時固定版本、digest 和相容矩陣。

## 版本矩陣

| 技術 | 本 repo 基線／實際 sample | 支援或適用條件 |
|---|---|---|
| .NET／ASP.NET Core | `net10.0`；本機驗證 SDK `10.0.400` | .NET 10 是 LTS，支援至 2028-11-14；ASP.NET Core 與 EF Core 跟隨相同 release lifecycle |
| .NET 9 | 不作新 sample 基線 | STS maintenance，支援至 2026-11-10；截至檢查日尚未停止支援 |
| .NET 8 | 相容性背景 | LTS 支援至 2026-11-10；若保留相容分支要明示剩餘期限 |
| C# | .NET 10 對應 C# 14；部分語法可在較舊 TFM 使用 | 實際可用語法仍受 SDK、TFM 和 `LangVersion` 影響 |
| EF Core | `Microsoft.EntityFrameworkCore.Sqlite` `10.0.11`（ProductMvc sample） | provider 版本要和 EF Core major 對齊；SQL Server、SQLite 的 translation／DDL 行為不可互換 |
| Redis | `Microsoft.Extensions.Caching.StackExchangeRedis` `10.0.11`；local image `redis:7.4` | Redis server、client/provider、TLS、ACL、persistence 和 eviction policy 要分開固定 |
| RabbitMQ | `RabbitMQ.Client` `7.0.0`；local image `rabbitmq:4-management` | queue type、publisher confirm、recovery 和 client API 版本要一起驗證 |
| SQL Server | Compose image `mcr.microsoft.com/mssql/server:2022-CU16-ubuntu-22.04` | Linux image architecture、CU、database compatibility level 和 production edition 要明示 |
| Kubernetes | manifests 使用 `apps/v1`、`autoscaling/v2`；VPA 使用 `autoscaling.k8s.io/v1` | HPA metrics API、VPA release 和 cluster minor version 必須有相容矩陣 |

官方 .NET 支援政策列出版本、release type、latest patch 和 end-of-support；不要把「目前 SDK 可安裝」寫成「產品仍受支援」。主要教學基線使用 .NET 10／C# 14；.NET 8／9 只作相容性閱讀背景。

## 閱讀規則

- 官方文件中的 default、stable、preview、deprecated 和 removed 只適用於該頁標示的版本；遇到版本敏感 claim 要回到版本矩陣。
- 教材中的 output、SQL、例外訊息和 performance number 只有在對應章節標明實測環境並由 sample 重新產生時，才可當成實測結果。
- local-only 的 `redis:7.4`、`rabbitmq:4-management`、development credentials 和 placeholder image digest 不能直接推導 production security profile。
