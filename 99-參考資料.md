## 版本註記

- 這份筆記的核心 API 以 .NET 8+ 為最低理解基線。
- `record`、`init`、nullable reference types、`IHttpClientFactory`、`WebApplication` 等不是 .NET 10 才出現；在 .NET 8 專案仍是主流用法。
- C# 12 primary constructors、collection expressions 在 .NET 8 SDK 可用；如果團隊的 language version 較舊，改寫成傳統 constructor / collection initializer 即可。
- C# 14 新功能屬於知道即可的延伸，不影響本教材的核心 Web API 設計。
